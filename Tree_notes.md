# Tree_notes — per-tree issue & solution log

Running log of the noteworthy issues hit while processing each tree, and how we resolved them. Companion to `field_data/field_measurements.csv`: the CSV holds the structured data and flags; **this file holds the qualitative story** — what was wrong, how was it diagnosed, and the fix used — so it can be written into the methods / limitations of the study.

Add a short entry for any tree that needed more than the default clean → measure path.

**Template**
```
## <Tree_ID>
- Issue:      what looked wrong
- Diagnosis:  what was actually going on
- Solution:   the fix used (tool, settings, steps)
- Confidence: resolved / partial / flagged — and any residual caveat for the write-up
```
