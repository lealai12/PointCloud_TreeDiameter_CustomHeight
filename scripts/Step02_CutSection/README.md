# Step 02 — Cut the trunk section

**Tool:** CloudCompare, by hand. No script.

| | |
|---|---|
| **Takes** | the prepared cloud from Step 01 |
| **Makes** | `Working\Segment_Disc\<tag>_Disc.bin` — a vertical chunk of the bole around the measurement site(s) |
| **Feeds** | Step 03 — clean the section |

## What happens here

Segment the whole-tree cloud down to a **trunk section**: tall enough to contain every measurement site for that tree with margin above and below, and — if lean correction will ever be wanted — at least ~2× the trunk diameter in height, because the stem axis can only be estimated from a segment that is taller than it is wide. Never from a thin slice.

Nothing is measured here. The section is the object every later step works on.

## This project's run

- **19 of 19** trees have a file at this stage — the first stage where that is true, and the reason it counts as its own step.
- For 13 of 19 trees the Step 02, Step 03 and Step 01 files were written within 60 seconds of each other: three *Save As* clicks from one session, no editing in between. The other six had real work done between Step 02 and Step 03 — see Step 03.
