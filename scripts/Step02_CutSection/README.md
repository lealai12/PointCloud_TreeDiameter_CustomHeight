# Step 02 — Cut the trunk section

Tools: CloudCompare or other Point Cloud Interface

Note: The (s) refer to cases in which multiple scans are needed per tree and will be fused in Step 3.

Steps:
1. Visually identify the locations(s) of the the scan(s) 
2. Create section of trunk that contains desired measurement site
    a. Segment should be as short as possible to reduce noise.
    b. If fusing is necessary, make sure that each section is tall enough to provide visible fusing points.
3. Save scan(s) as .ply file and select Binary if prompted to choose.
